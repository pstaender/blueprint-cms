The icons of the panel, usable as `icon` in blueprints (page types, tabs, …): `icon: calendar`. Besides a name, `icon` can be any text like an emoji (`icon: 📝`) or an inline image (`icon: data:image/svg+xml;base64,…`), see [Panel guide](/guides/panel#icons).

The names follow [Kirby's icon set](https://getkirby.com/docs/reference/panel/icons), without its brand logos. The icons are drawn by hand for Blueprint CMS, so no third party license applies.
