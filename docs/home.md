Blueprint CMS (BPCMS) is a flat file CMS inspired by [Kirby](https://getkirby.com). Content lives in files, project code in `site/`, and blueprints describe the data structure and the panel views.

- [Guides](01_guides/page.md) – step by step introductions
- [Reference](02_reference/page.md) – every option, field, helper and class
- [Examples](03_examples/page.md) – copy & paste solutions

This documentation is itself structured like a `content/` folder: every page is a (numbered) folder with a `page.md`.
