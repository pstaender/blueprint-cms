Blueprint CMS (BPCMS) is a flat file CMS inspired by [Kirby](https://getkirby.com). Content lives in files, project code in `site/`, and blueprints describe the data structure and the panel views.

- [Guides](/guides/) – step by step introductions
- [Reference](/reference/) – every option, field, helper and class
- [Examples](/examples/) – copy & paste solutions

This documentation is itself a content folder (`docs/`, served with `"contentFolder" => PROJECT_DIR . "/docs"`): a page is a `name.md` file, or a folder with a `page.md` if it has subpages. `sort` in the front matter orders the menu.
